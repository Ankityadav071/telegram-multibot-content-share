# V9.7.1 — Date-wise scheduling + video-frame covers

## Admin Bot
- Video Management now has **Date-wise Schedule**.
- Previous / Today / Next navigation shows the selected calendar date independently.
- The panel shows video entries, direct videos, collections, and collection-item counts for that date.
- Scheduled items remain actionable with Edit / Reschedule and collection controls.

## Storage Bot — video-frame covers
New cover choices during single and new bulk uploads:
- **Auto Random Video Frame** — extracts one random frame from the uploaded video.
- **Pick Video Shots** — choose a preset or enter custom `count interval`, e.g. `8 5` for 8 shots about 5 seconds apart.
- The generated shots are sent into the admin chat so the uploader can visually inspect them and choose exactly one shot as the cover.
- Selected generated covers are copied into Primary at final Save, so the catalog keeps a portable Primary message reference rather than relying only on a bot-local file_id.

Frame generation uses ffmpeg/ffprobe on the VPS. Large videos may fail frame generation when the Telegram Bot API cannot download the source; the existing Default / Random Default / Manual cover paths remain available.

No database reset or destructive migration is used.
