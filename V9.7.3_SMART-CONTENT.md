# V9.7.3 — Smart Content

Adds a practical Smart Best Frame cover mode on top of the existing cover system.

- Samples frames across the full video timeline instead of only the beginning.
- Scores candidates locally for detail/sharpness, contrast and usable exposure.
- Shows the selected frame before save; admin explicitly chooses Use This Frame.
- Works for single uploads and bulk collection cover flow when a video is available.
- Existing Default, Random Default, Random Video Frame, Shot Picker and Manual Cover remain available.
- No automatic deletion, overwrite, or DB reset.
