V9.7.2 — Smart Operations Upgrade

1. Admin date-wise Publishing Planner
- By Date now opens a day-specific publishing queue.
- Previous / Today / Next navigation.
- Upcoming 7 Days summary.
- Shows scheduled videos, unique collections, collection items and queue times.
- Existing upload-by-date command/data remains available and no content is deleted.

2. Storage Health
- New read-only Storage Health dashboard and /storagehealth command.
- Checks Primary/Backup/(optional 3rd Content) bot access.
- Reports missing Primary/Backup/3rd-source mappings, missing covers and ready-copy count.
- No automatic deletion or mutation.

3. Possible Duplicate Warning
- New non-blocking scan when a video arrives.
- Uses file size + near-equal duration to surface possible existing matches.
- It is only a warning; legitimate re-uploads remain allowed.

Existing DB is preserved and migrations remain additive/idempotent.
