# V9.7.0 — Content Workflow + Daily Analysis

## Added
- Content Overview with exact total videos, collections, live videos, scheduled videos, scheduled collections, and scheduled collection items.
- Subcategory picker during single and bulk content creation, showing existing catalogue subcategories for the chosen category with counts.
- Structured subcategory is stored while free-form tags remain available.
- Quick scheduling presets (+2h, +6h, tomorrow 00:05, tomorrow 18:00), 7-day date picker, common time choices, and manual date/time entry.
- `/dailyanalysis` and in-bot Daily Analysis with previous/next day navigation, content counts, schedule counts, deliveries, active users, searches, ad unlocks, redeems, and top delivered videos.

## Compatibility
- Existing SQLite data is preserved; no reset or delete operation is included.
- Existing recovery, delivery repair, catalogue, upload, and bulk flows are preserved.
