# V9.7.4 — Repair & UX Hardening

- Fixed Admin Permanent Delivery Bot Health Monitor calling a missing `bot_health_snapshot()` API.
- Added a read-only permanent-bot health snapshot derived from the same eligibility rules used by routing.
- Added Storage Bot saved-video recovery actions: `Rebuild Mapping` and isolated `Send Replacement`.
- Replacement copies new media to Primary + Backup + optional 3rd Content before changing the live DB mapping; partial failures leave the old mapping untouched.
- Replacement mode is isolated from normal Single/Bulk upload flows and is cleared safely on cancel/completion.
- Existing Video ID is preserved during replacement, so Catalogue/Mini App watch targets remain valid.
- Made Catalogue Bot's reply keyboard persistent and restored it after listing/empty-result rendering, while keeping inline Back to Menu navigation.
- Hardened first-run permanent-bot store directory creation for custom store paths.

No DB reset, destructive migration, or Netlify/VPS API change is required for these fixes.
