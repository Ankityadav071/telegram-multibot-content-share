# V9.8.0 Hotfix — Catalogue Footer Error

Fixed a runtime `NameError` in `catalog_bot.py` after catalogue video cards were sent.

The listing footer incorrectly referenced an undefined `nav` variable. This caused the
catalogue bot's global error handler to send `⚠️ Something went wrong — please try again.`
after the videos had already been delivered.

The footer now uses the already-computed `has_next` boolean. No Delivery Bot resolver,
video mapping, database schema, or storage behavior was changed.

Validation: Python compileall passed for the full package.
